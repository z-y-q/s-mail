# s-mail 设计审计蓝图（2026-10-30）

> 视图层扫描（找「有引擎无入口」的功能）。屏幕截图受系统录制权限限制，视觉

## 1. 颜色（WCAG 实算结果）

达标项（无需动）：深色模式全部文本组合 4.6:1–9.3:1；星标金、成功绿、危险红
在两种主题下均达标。

| 组合 | 实测 | 问题 |
|---|---|---|
| 浅色 accent 文字/浅窗底（顶栏、筛选按钮的强调色文字） | 3.69:1 | 12px 小字未达 AA 4.5:1 |
| 白字/accent 按钮（写邮件、发送、保存并使用） | 3.61–4.02:1 | 13px 未达 AA（Apple 惯例如此，但低于 WCAG） |
| 浅色次要文字/侧栏底 | 4.27:1 | 11px 未达 AA，边缘 |

改法（均 S）：
- C1 浅色模式强调色文字场景改用 `#0071E3`（Apple 官网用的更深变体，白底
  对比 4.6+），按钮底色维持 systemBlue 不变（白字按钮是业界惯例，可接受）。
- C2 浅色次要文字在侧栏场景提到 `#636366`（4.6:1）。

## 2. 字体与排版层级

现状：`.size()` 使用频次 12px×97、13px×44、11px×43、10px×11、14px×7、
20px×3、17/16 各 1。五档密集（10–14px），11 与 12 视觉难区分——层级噪声。

Apple Mail 桌面端实际只用三档：正文 13、辅助 11、标题 17。对照建议收敛为：

| 语义 | 现状 | 目标 |
|---|---|---|
| 列表正文/正文 | 12 与 13 混用 | 统一 13（T1，S：批量替换 12→13 的正文场景） |
| 次要信息 | 11×43 + 10×11 | 统一 11（T2，S：10→11） |
| 页面标题 | 20 | 17 Semibold（与阅读主题同档，Apple 惯例）（T3，S） |
| 空态大图标 | 28/30/34 | 保留（装饰字符非文字层级） |

字体栈：`SF Pro Text` 硬编码（theme.rs:258），Linux/Windows 回退默认字体——
跨平台无栈（README 已声明 Windows 受阻，可后置；Linux 用户会拿到非 SF 的
回退观感）。改法：按平台选栈 `SF Pro Text` / `Inter`（T4，S）。

## 3. 布局

- L1 三栏宽度全部固定：侧栏 200（list_view.rs:334）、列表 380（:1010）、
  阅读 Fill。最小窗宽 980 时阅读窗只剩 ~390px，长行正文体验差。
  改法：侧栏与列表列宽可拖拽（iced 无现成 split 组件，需 mouse_area 自实现
  拖拽分割条，M）；最小改造为列表 380→420 且侧栏收窄 180（S）。
- L2 无右键菜单（on_right_press/mouse_area 全项目零使用）：邮件右键
  移动/删除/标星是桌面邮件客户端的高频路径（M：mouse_area + overlay 菜单）。
- L3 拖拽把邮件拖进文件夹 ✅ 已实现（2026-10-31）：自实现拖拽手势
  （按下候选→超 6px 成拖→松开投放，drag.rs），幽灵浮层 + 目标高亮，
  多选整批移动；侧栏命中表每帧登记，Esc 取消。
- L4 阅读窗操作条已分两行（本轮已修），但正文卡片最大宽度不设限——超宽
  窗口下行长过长伤可读性，建议正文卡 max_width 760 居中（S）。

## 4. 主题

- T-1 深/浅双主题 + 系统跟随 + 手动切换已完备；图标已单色化。健全。
- T-2 无「紧凑/舒适」密度切换：列表行高固定 52px，信息密度偏好因人而异
  （M：行高与间距参数化进 prefs）。
- T-3 主题切换即时代码生效，但无过渡——iced 无动画系统，接受现状。

## 5. 功能完整性：有引擎、无入口（最高性价比缺口）

- F1 **过滤规则引擎完整、零界面**：`Rule` v2 条件/动作模型（config.rs）+
  同步时应用（sync.rs apply_rules）全部就绪，但 smail-ui 零引用——用户只能
  手改 config.toml。设置页账号下加规则编辑器（列表 + 条件行 + 动作下拉）
  是把已建成的引擎点亮，价值最大（L：表单与序列化 UI）。
- F2 通讯录只有收集与删除：无搜索、无「写信」快捷入口（M）。
- F3 无打印 / 导出 PDF（.eml 导出已有）（P2）。
- F4 无稍后处理/置顶（P2）。
- F5 入口可发现性：同步间隔、PGP、签名、钥匙串、AI 全部藏在「＋账号 →
  已有账号行」的行内按钮里，首次使用者不可发现（S：设置页加分组标题或
  「高级」分区）。

## 6. 排期建议

- **P0（点亮已建成的能力）**：F1 规则编辑器、F5 入口重组。
- **P1（可读性与层级）**：T1–T3 字号收敛、C1–C2 两处对比度、L4 正文
  max_width。
- **P2（交互升级）**：L1 列宽拖拽 ✅、L2 右键菜单 ✅、F2 通讯录搜索 ✅、
  L3 拖拽移动 ✅。
- **P3（远期）**：密度切换、打印、跨平台字体栈。
